# Contributing to GD3 Plugin Store

Thanks for your interest!

## Reporting Bugs

1. **Search first** - check [existing issues](https://github.com/60plus/gd3-plugin-store/issues) to see if your bug has already been reported
2. **Use the Bug Report template** - fill in all required fields
3. **Include version info** - plugin version and GamesDownloader version
4. **Screenshots help** - attach screenshots if the issue is visual

## Requesting Features

1. **Search first** - someone may have already suggested it
2. **Use the Feature Request template** - describe the feature and why it would be useful
3. **One feature per issue** - keep it focused

## Plugin Development

Want to create your own plugin? See [gd3-plugin-template](https://github.com/60plus/gd3-plugin-template) for:
- Starter templates (metadata, theme, lifecycle, widget)
- Hook reference with all specs
- Working examples (NEON HORIZON, PPE.pl, Translator)
- Vue SFC compilation docs

## Questions

For general questions about GamesDownloader or plugins, open a [Discussion](https://github.com/60plus/gd3-plugin-store/discussions) instead of an issue.
